# MulTape 外语磁带

**网址：<https://aarynyan-cell.github.io/OoFR/>**

把一段外语文本变成可以听读、查词、跟读、讲解和复习的“磁带课程”。手机和电脑的浏览器都能用，免费，没有账号，学习数据只保存在你自己的设备上。1.0 可以学法语、西班牙语、中文。

- iPhone：用 Safari 打开 → 分享 → 添加到主屏幕，以后从主屏幕图标打开（离线也能用）。
- 旧版 OoFR 法语磁带备份在 <https://aarynyan-cell.github.io/OoFR-3/>，数据不受影响；在 MulTape 的“我的 → 共享与备份”里可以把它的磁带和词句本复制过来。
