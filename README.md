# OoFR 法语磁带

OoFR 法语磁带是一个本地优先的法语/英语学习 PWA，也可以作为 Microsoft Edge / Google Chrome 插件使用。课程用于学习，磁带用于分类素材，词句本用于收藏和复习。

- 手机/网页：<https://aarynyan-cell.github.io/OoFR/>
- macOS 测试版与浏览器插件：<https://github.com/aarynyan-cell/OoFR/releases/tag/v1.0.0>

## 当前能力

- 课程首页支持任意法语/英语文本、三语系统设置、紧凑播放器、逐句真实录音、开放词典和词句卡片练习。
- 粘贴或导入素材后自动建议标题、分类、语言和 A/B/C 对话人；修订建议会说明原因，只有人工确认后才替换原文。
- 输入法语文本，按全文、换行句或单词播放；全文、单句和单词共用播放/暂停/继续逻辑。
- 把任意文本保存成素材，并归入自定义磁带分类。
- 在磁带页筛选、搜索、新增、编辑和删除素材，每条素材可进入独立课程。
- 点击单词弹出生词面板；生词显示橙色，标为 `got` 后显示绿色。
- 词卡按词性决定显示规则：动词变位归到原型（如 `voudrais → vouloir`），名词、形容词、代词等保留实际遇到的词形（如 `jours`、`ça`）；固定表达保持整体。
- 单词本支持 `all`、`new`、`got`、`DIY` 系统筛选，以及自定义单词本的新建、编辑、删除。
- 没有音标或中文释义的词会自动出现在 `DIY` 单词本中。
- 单词本支持法语音标、中文释义、状态编辑、见过的词形记录和搜索。
- 内置分片式法语/英语开放词典会自动填充词性、音标、简中释义、英文释义和法语词形；法语包含约 9.4 万词条和 67.6 万词形映射，英语包含约 12.7 万词条。
- 打开页面时显示“读取课程 → 恢复设置 → 绘制界面 → 可以开始”的分步进度；基础界面先就绪，词典只加载命中词所在的小分片并缓存，不会在首页一次载入整套数据。
- “我的”页集中放置完整数据导入/导出、单词本选择范围导入/导出、导入提醒和问题反馈信息。
- 单词本导出可选择 all、new、got、DIY、当前选中词本或自定义单词本；导入会先预览，并可选择重复词保留本地状态或使用导入状态。
- Notice 提醒、读者页和“我的”页布局已针对桌面与手机窄屏做对齐优化。
- 朗读页的播放设置已折叠到文本输入卡片右上角，输入区和朗读区保持上下排列。
- 支持 PWA：通过 HTTP/HTTPS 访问时可离线缓存并添加到手机桌面。
- 支持 Chrome / Edge Manifest V3 插件：点击插件图标打开完整练习页面。
- 课程可以导出 `.oofr-learning.json` 学习包；手机导入后可离线使用电脑端已生成的译文、固定表达、逐句讲解与相关词典缓存。
- macOS 测试版会检测并复用现有 Ollama；缺少运行时或 `gemma3:4b` 时可在应用内下载、启动和预热，无需手动输入终端命令。

## 本地使用

直接打开：

```text
index.html
```

本地文件方式可以使用主要功能。若要测试 PWA 离线缓存，请在项目目录启动一个本地 HTTP 服务：

```sh
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/
```

## GitHub Pages 发布

1. 在 GitHub 新建一个仓库。
2. 把本项目推送到仓库的 `main` 分支。
3. 打开仓库 `Settings` -> `Pages`。
4. `Source` 选择 `Deploy from a branch`。
5. `Branch` 选择 `main` 和 `/root`。
6. 保存后等待 Pages 生成网址。

应用使用相对路径，可以部署在 GitHub Pages 的仓库子路径下。公开仓库会公开源代码和静态资源；不要提交个人导出的 JSON 数据、私钥、证书或未授权素材。

## 浏览器插件

当前 Edge 和 Chrome 都作为正式支持的插件目标。默认法语声音分别为 Edge 的 `Microsoft Henri Online (Natural) - French (France)` 和 Chrome 的 `Google français`。

开发阶段可以用“加载已解压的扩展程序”的方式安装：

### Chrome

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹。
5. 点击 OoFR 法语磁带插件图标，打开完整练习页面。

### Edge

1. 打开 `edge://extensions/`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目文件夹。
5. 点击 OoFR 法语磁带插件图标，打开完整练习页面。

普通用户从 Chrome Web Store 或 Microsoft Edge Add-ons 安装时，不需要打开开发者模式。发布到插件商店前，先生成提交审核用的 zip 包：

```sh
./scripts/package_extension.sh
```

生成文件位于 `release/oofr-french-tape-extension-v1.0.0.zip`。商店上传 zip 包，不是直接上传整个 GitHub 仓库。更多发布准备见 `PUBLISHING.md`。

插件版使用 `chrome.storage.local` 保存完整个人数据，并用 `chrome.storage.sync` 同步少量播放设置。完整专辑、磁带、朗读记录和单词本建议用“导出 / 导入”迁移。

## 数据

网页/PWA 版数据默认保存在浏览器 `localStorage` 中，逐句录音保存在 IndexedDB。插件版完整数据保存在 `chrome.storage.local` 中。升级到 1.0.0 不会清空课程、磁带、词句本、学习记录或 AI 缓存。

### 电脑与手机迁移

1.0.0 暂不开放账号登录与自动同步，也不会初始化 Supabase 或发出同步请求。迁移方式分为两种：

- 在课程页导出“学习包”，把单门课程连同译文、固定表达、逐句讲解、相关词典缓存和词句本条目带到手机。遇到同一课程可更新原课程，也可导入为副本。学习包不包含录音、设备设置或本地 AI 地址。
- 在“我的”页导出“完整数据”，用于换浏览器、换电脑或迁移全部磁带、素材、词句本和播放设置。导入完整备份会覆盖目标设备的数据，操作前应先保留目标设备备份。

只迁移某一部分生词时，使用“词句本”导入/导出。词句本导入会与本地数据取并集，不会删除本地词条；重复词可以选择保留本地 `got/new` 状态，或使用导入文件的状态。

## 词库来源

完整词典由 `scripts/build_dictionary.py` 生成，法语主要来源为 Kaikki/Wiktionary、Morphalou 3.1 和 FreeDict，英语主要来源为 Open English WordNet 2025、ECDICT 和 FreeDict。ECDICT 也用于补充法语英文释义对应的简中义项；无法仅凭词头消歧的常用同形词由 OoFR 校订层处理。浏览器通过 `dictionary.js` 按哈希分片读取 `dictionary/`，详见 `THIRD_PARTY_NOTICES.md`。`lexicon.js` 继续作为小型兼容后备词库。

查词运行时优先使用本地结构化词典，精确保留重音和撇号，只有精确查询失败时才使用无歧义的宽松别名，因此 `ça/ca`、`à/a`、`où/ou` 不会互相覆盖。显示前会统一修复常见乱码、清理来源备注和重复义项，并按“词头—词性—音标—编号义项—词形—来源”的固定格式呈现。词义始终以本地开放词典和 OoFR 人工校订层为准，不让生成式 AI 改写义项；本地未命中时仍保留 Wiktionary 免费回退。这样查词无需 API Key、不消耗云端 token，也不会因小模型补写而污染词卡。

### 本地 AI 与 macOS 测试版

OoFR 的素材深度分析、课程翻译和逐句语法讲解可以交给本机 Ollama，不需要云端 API Key。课程译文、固定表达和逐句讲解会在后台分批生成并保存在对应课程数据中；原文和模型设置不变时会直接复用，不会重复推理。客户端会复用模型选择并让模型在内存中保持 30 分钟，减少反复加载。词典与生成式 AI 分层：AI 不改写词义，以免小模型幻觉。安装并启动 Ollama 后，至少拉取一个支持结构化输出的指令模型：

```sh
ollama pull gemma3:4b
ollama serve
```

macOS 测试版会在首次启动时检测系统、处理器、磁盘空间、Ollama 和模型。它会优先复用用户已有的 Ollama 与 `gemma3:4b`；缺失时仅在用户确认许可后下载到 `~/Library/Application Support/OoFR/`，并且只监听 `127.0.0.1`。测试版使用 ad-hoc 签名，但尚未经过 Apple Developer 身份签名或公证，首次打开仍可能需要在 Finder 中右键选择“打开”。

浏览器本地版打开后会自动检测本机 AI；也可以在“我的 → 语言与智能工具”保留地址 `http://127.0.0.1:11434`，手动点击“检测本地 AI”。模型设为 `auto` 时，OoFR 会优先选用已安装模型中体积较小的一个；明确指定模型时不会擅自替换，只有指定模型已不存在才会回退到可用模型。之后可以：

- 在新建素材页点击“重新智能分析”，获得分类、说话人、固定表达和逐项纠错建议；
- 生成课程时，用 Ollama 一次批量生成逐句译文；
- 在每句下点击“AI 讲解”，查看句式骨架、语法点、词形变化、易错点和替换例句；
- 词语“查看详情”当前固定使用本地词典、词形数据和可解释规则；结合语境的 AI 词语详解留到后续版本。

GitHub Pages 在线版 1.0.0 不调用本机或云端生成式 AI，也不会在浏览器中保存云端 AI 密钥。它可以直接使用开放词典、朗读、录音、课程、练习以及学习包中已缓存的 AI 内容；缺少的内容会提示回到 macOS 版生成。Chrome / Edge 插件包仍可访问 `127.0.0.1` 和 `localhost`，连接用户主动运行的本机 Ollama。模型生成结果仍可能出错；OoFR 会把 AI 修订作为建议展示，只有人工确认后才替换原文。
