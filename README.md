# OoFR 法语磁带

把任意法语文本变成可以听读、跟读、练习和复习的“磁带课程”。手机和电脑都能用，免费，学习数据只保存在你自己的设备上。

## 开始使用

- **手机 / 网页**：<https://aarynyan-cell.github.io/OoFR/>
  iPhone 用 Safari 打开 → 分享 → 添加到主屏幕，以后从主屏幕图标打开（离线也能用）。
- **Mac 应用**：<https://github.com/aarynyan-cell/OoFR/releases/latest> 下载 “OoFR Online”（Intel 和 Apple 芯片都能用）。
  应用没有付费签名：第一次打开如果提示无法验证开发者，到“系统设置 → 隐私与安全性”里点“仍要打开”。

手机和电脑各自都能完整使用（翻译、讲解、自然朗读），不需要互相依赖；扫码连接后，磁带、素材和词句本会自动同步。

## 能做什么

- **听读**：逐句朗读，点句子只播这一句，底部播放键从当前句一直播下去；法 / 中 / 双语显示；每句读几遍（1–5）；后台播放（锁屏或切到别的 App 时整课接着放）。
- **查词**：点任意单词查离线词典（释义按词性分组、常用词有中文释义）；词句页也能直接查词；发现释义有误可以报错、修正。
- **跟读**：录下自己的朗读，自动和原句对比，给出总评和建议收藏的词句，可回放、导出音频。
- **练习**：听音选句、选词填空、连词成句，自动朗读，错题可收藏。
- **复习**：词句本按 FSRS 间隔复习；“学习记录”里看每天的学习情况。
- **AI 翻译与讲解**：整课译文和逐句语法讲解，用你自己的免费密钥（见下文）。生成过的内容保存在本机，之后不联网也能看。
- **自然的法语朗读**（手机上也有，见下文）。

## 朗读声音

| 声音 | 说明 |
|---|---|
| 手机本地语音（Siwis 女声 / Tom 男声） | 在“我的 → 朗读声音”下面点“下载”，一次约 96 MB（第二个声音约 64 MB）。之后在手机上直接朗读：不联网、不用电脑、不用密钥，没有次数限制。下载后默认使用。 |
| Gemini 在线声音（可选） | 加一个 Gemini 免费密钥即可使用。免费额度很小（每天约 20 次请求），所以只用来读课文句子，一次读一整段，读过的句子会存在本机。 |
| 电脑朗读 | 手机扫码连接 Mac 应用后，可以用 Mac 的增强版声音朗读，读过的句子存在手机上，断开后也能播放。 |
| 系统声音 | 手机或浏览器自带的基础声音，随时可用。 |

## 在线 AI（免费，用你自己的密钥）

在“我的 → AI 翻译与讲解”里填入免费密钥，有一个就能用：

- **Groq**（推荐）：Qwen3.8-27B，翻译和讲解又快又准。免费额度约每天 1000 次请求。
- **硅基流动**、**智谱**：作为备用，Groq 忙或不可用时自动接上。
- **Gemini**：只用于上面的在线朗读声音。

几点说明：

- 密钥只保存在你自己的设备上：不会写进网页、不会上传到 OoFR、不进备份、不会同步。手机扫码连接电脑后，可以在手机上一键“从电脑导入密钥”，只经过两台设备之间的直连。
- 需要翻译或讲解的句子会发给你选的服务商处理。
- Groq 和 Gemini 在中国大陆需要能访问国外网络；硅基流动和智谱在国内可直接使用。
- Mac 应用里如果没有填密钥，仍可以使用本机 Ollama 生成（不联网）。

## 连接手机和电脑

在 Mac 应用的“我的 → AI 翻译与讲解”里显示二维码，用手机相机扫码配对。之后在同一个 Wi‑Fi 下：磁带、素材和词句本双向自动同步；手机可以用电脑的增强版声音；可以把电脑上的密钥导入手机。连接是两台设备直连（WebRTC），不经过任何服务器。学校、公司等禁止设备互连的 Wi‑Fi 下，可以让电脑连手机热点。

## 从旧版本搬数据

- 在同一个浏览器里用过 2.0 的话，第一次打开时会自动复制一份 2.0 的磁带、课程、词句本、录音和学习进度（2.0 的数据保持不变）。
- iPhone 上每个“添加到主屏幕”的 App 各自存放数据，可能复制不到。这时在旧版的“我的”里“导出完整备份”，再在这里“导入备份或学习包”。
- 1.0 的数据可以在“我的”里一键导入；也支持导入 1.0 / 2.0 的备份和学习包。

## 开发

应用代码在 [`v2/`](v2/)（Vite + React + TypeScript + Dexie，Mac 应用用 Tauri 2，在 [`v2/desktop/`](v2/desktop/)）。详细结构和数据安全约定见 [`v2/README.md`](v2/README.md)。

```sh
cd v2
npm ci
npm run dev        # http://localhost:5173
npm test           # Vitest 单元测试
npm run build      # 类型检查 + 生成 dist/（含离线 service worker）
```

- Mac 端测试：`cd v2/desktop/src-tauri && cargo test`
- 词典脚本测试：`python3 -m unittest discover -s v2/scripts -p "test_*.py"`
- 发布流程见 [`PUBLISHING.md`](PUBLISHING.md)，版本说明见 [`RELEASE_NOTES.md`](RELEASE_NOTES.md)，隐私说明见 [`PRIVACY.md`](PRIVACY.md)，第三方数据和组件的许可见 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)。

### 仓库结构

| 位置 | 内容 |
|---|---|
| `v2/` | 现在的应用：网页 / 手机 PWA，以及 `v2/desktop/` 里的 Mac 应用 |
| `dictionary/` | 离线词典数据（按需下载的分片），构建时拷进网站 |
| `scripts/` | 生成离线词典的脚本 |
| `.github/workflows/pages.yml` | 推送到 `main` 后自动测试、构建 `v2/` 并发布到 GitHub Pages |
| `MulTape/` | 另一个独立项目（多语言版），与本应用无关 |
| 根目录其余文件 | 1.0 时代的旧文件，现在的应用不使用，仅作参考；完整历史见存档仓库 |
