# 已知问题

## iPhone 跟读：重录有时录不到声音（暂缓，2026-10-21 记录）

**现象**：在 iPhone 上跟读，录过一遍之后，只要放过声音（听原声，或听我的），下一遍录音就是空的（提示“没有录到声音”），之后每一遍都空，直到刷新页面（主屏幕 App 要关掉重开），或者等大约一分钟才自己恢复。

**规律**（四轮真机测试，iOS 26.6.1，Safari 测试页 + 配对的 Mac 测试版）：

- 页面打开后、还没录过音时放声音，不影响录音。
- 连续录几遍、中间不放声音，都正常。
- 录过一遍 → 放任何声音 → 下一遍起全是空的。刷新页面立刻恢复。
- 坏的时候：麦克风轨道是 `live`、没有 `muted`，MediaRecorder 一个数据块都没有（0 字节），浏览器自带的语音识别也什么都没听到。也就是整个麦克风输入停了，不只是录音器。

**试过但没用的办法**（代码都已撤回或保留为无害改动）：

| 轮次 | 改动 | 结果 |
| --- | --- | --- |
| 2.0.1 | 新一遍等上一遍语音识别结束；麦克风静音时重新申请一次；`MediaRecorder.start(250)` | 没解决 |
| 1 | 2.0.3：手机播放器在暂停、读完、停止后清空 | 没解决（灵动岛问题修好了） |
| 2 | 跟读期间 `navigator.audioSession.type = "play-and-record"`；录空后切换一下 audio session | 没解决，已撤回 |
| 3 | 关掉回声消除、降噪、自动增益（普通麦克风） | 没解决，而且录音小了约 15 倍，已撤回 |
| 4 | 波形、响度、合并录音改用 OfflineAudioContext（不再开实时 AudioContext） | 没解决；改动无害，保留 |

**下次可以试**：

1. 整个跟读期间只打开一次麦克风、各遍之间不关（每遍新建 MediaRecorder），这样放声音时麦克风一直在，不需要“重新启动”。代价：跟读页上麦克风指示灯一直亮；要确认放原声的音量不变小。
2. 用 Web Audio（`MediaStreamAudioSourceNode` 取 PCM）代替 MediaRecorder 录音，并同时看语音识别有没有声音，分清是录音器还是麦克风本身的问题。
3. 原声在跟读页改用 Web Audio 播放（不经过 `<audio>` 元素），看是不是 `<audio>` 播放引起的。
4. 查 WebKit 的相关 bug；如果实在没有办法，录空时自动保存状态并刷新页面。

**测试方法**：见记忆里的“发布前在真手机上测”：Mac 上开测试版窗口（`OOFR_SUPPORT_DIR`）、`npm run dev:phone-https`，手机扫码进 https 测试页；手机上的事件会写到 `v2/devlog.log`（`src/app/devlog.ts`，只在测试版里有）。
