# 本机 AI 模型选择（2026-10-19）

在作者的 Mac（M4，24 GB）上用 `v2/scripts/compare_models.py` 对比，同一批题目、关闭“思考”模式。

| | gemma3:4b | qwen3.5:9b |
|---|---|---|
| 运行时内存 | 3.7 GB | 5.6–6.2 GB |
| 速度 | 约快一倍 | 一句讲解约 50 秒 |
| 单词释义（24 个多义词） | 7 个没按格式返回；错误：temps 时态→“语态”，tour 车→“车河”，étaler 分期→“推迟” | 24 个全部返回，基本准确 |
| 整句翻译（10 句） | 一处意思译反：“为了不错过火车”→“为了赶不上火车” | 全部正确 |
| 句中词义（8 例） | 基本正确 | 基本正确 |
| 句子讲解（6 句） | 多处语法错误：voudrais 说成虚拟式、dont 说成指示代词、s'est levée 说成虚拟式 | 大多正确；复杂时态仍有错：把条件式过去时说成“虚拟语气”，易错点里给出错误的 “n'aurais pas venu” |

结论：差距大，选 **qwen3.5:9b**。gemma4:26b 质量同样好，但要约 20 GB 内存，在 24 GB 的机器上会严重拖慢其他程序。

仍要注意：
- qwen3.5 默认会先“思考”很久，调用时必须传 `think: false`。
- 复杂语法讲解两个模型都会出错。2.0 生成讲解时，要把词典里查到的确定事实（词形、时态名称）放进提示词，并统一术语对照（如 conditionnel passé = 条件式过去时），不让模型去猜时态。
- 每次调用都传较短的 `keep_alive`，用完就释放内存（作者的 Ollama 默认会保留 30 分钟）。
